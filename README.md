# Blockstorm

Blockstorm is a browser-based, Vortex-inspired multiplayer party game. The first playable experience is **Don't Press the Button**: share one island, try to survive the button's disasters, and see who is left standing.

## Play

- **Live app:** deployed on Vercel (link is added after deployment).
- Open the game and choose **Zagraj teraz** to host a room.
- Click **Zaproś znajomego**, copy the invite link and send it to a friend. Both players need to keep the game tab open.
- No account or install is required. The game supports up to 8 players per room.

## Disasters

- Tornado — keep moving and avoid the vortex.
- Earthquake — dodge cracks and get to safe platforms.
- Tsunami — climb the tower before the wave arrives.
- Meteor shower — move out of the marked impact zones.

## Controls

- **WASD** or **arrow keys** — move.
- **Space** — jump.
- **E** — press the button.
- On phones and tablets, use the on-screen movement pad and jump button.

The room host runs the authoritative game simulation in their browser and shares updates through an encrypted MQTT-over-WebSocket relay. The invite link includes the room's AES-GCM key, so only share it with the people you want to invite. The default relay is Eclipse Mosquitto's public test broker, which is a community testing service and can be temporarily unavailable; the game tab must remain open for the room to exist.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Tech

Vite, TypeScript, Three.js, MQTT.js, and Web Crypto. The island and disaster effects are generated by the game, and no Roblox assets or player data are used.
